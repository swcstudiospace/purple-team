## Wave Structure

1. **Wave 1 (`n1` · `SPE-14018`)**: Audit codebase architecture, 4th Hat (`Red`) identity, and milestone state in `.planning/`.
2. **Wave 2 (`n2`, `n6` · `SPE-14019`, `SPE-14022`)**:
   - Input sanitization (`__proto__`, `constructor`, `prototype` stripping, 2MB payload cap) and `AbortController` execution timeout runner (`src/teams/guardrails.ts`).
   - Blue Hat tools (`src/teams/blue/tools.ts`): Workflow Sequencer, Session & Decision Ledger, Execution Monitor & Dispatcher.
   - White Hat tools (`src/teams/white/tools.ts`): Structured Data Inspector, Evidence & Fact Collector, Information Gap Analyzer.
   - Black Hat tools (`src/teams/black/tools.ts`): Risk & Failure Mode Analyzer, Rule & Policy Validator, Stress & Edge Case Prober.
   - Cross-Hat Extra Utility Tools & Composable Skills (`src/teams/skills.ts`): Context Transformer, Artifact Diff, Snapshot Manager, Batch Runner, and multi-Hat composable Skill presets.
   - Server REST endpoints (`/api/teams/blue/tools/*`, `/api/teams/white/tools/*`, `/api/teams/black/tools/*`, `/api/teams/skills/*`) and MCP tools (`src/mcp-server.ts`).
3. **Wave 3 (`n3`, `n4`, `n5` · `SPE-14020`, `SPE-14021`, `SPE-14023`)**:
   - CSS token expansion (`docs/assets/tokens.css`): Per-Hat semantic tokens, desktop multi-pane split layout (`>=1024px`), mobile bottom navigation bar & bottom-sheet drawers (`<768px`), `env(safe-area-inset-*)`, `>=44px` touch targets, and `prefers-reduced-motion` compliance.
   - Shared UI shell (`docs/assets/shell.js`): Command Palette (`Cmd/Ctrl+K`), Hat switcher shortcuts, ARIA live announcer, session draft persistence across view switches, platform capability fallbacks (clipboard, share, download), and `Send to Hat` context forwarding.
   - Interactive 4-Hat Tool & Skill Workspaces (`docs/hats.html`, `docs/defend.html`, `docs/overview.html`, `docs/index.html`) + PWA/mobile manifest (`docs/manifest.webmanifest`).
4. **Wave 4 (`n7` · `SPE-14024`)**:
   - Automated unit/integration tests for all new tools, skills, security guardrails, and UI/desktop/mobile contracts.
   - Full verification gates (`npm run lint`, `npm run typecheck`, `npm test`, `npm run verify-claims`, `npm run doctor`, `npm run build`).
