1. **`purple-run` SSE event** on `/api/events`: payload projects 1:1 into n6's `PurpleRunData` (`data-purple-run` DataUIPart); `errorCode` uses n5's 8-code taxonomy; counters = discovered/fetched/skipped/bytes; cancel via extended `/api/mission/stop` (works pre-mission).
2. **`oauthStatus().claude`** = `{ label, connected, expiresAt?, tier?, needsReauth? }` — no secrets, ever.
3. **GitHub status** = `{ configured, connected, login?, avatarUrl?, scopes?, expiresAt? }`; `anonymous` mode when unconfigured.
4. **URL validator** is ONE module (`src/recon/repo-url.ts`) imported by UI and server — no second implementation.
