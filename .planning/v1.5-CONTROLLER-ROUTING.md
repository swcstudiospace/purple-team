3. **No typed input pinning.** The mounted planner accepts no `inputs`, `depends_on`, custom task rows, amendment operation, or existing-task `acceptance` patch. `swarm_assignment` accepts only task/correlation IDs, and `swarm_transition` only state/reason/dry-run. That is a signed acceptance condition, **not** a populated typed `inputs[]` object and not an amendment to original T1b29-be. It does not erase the previously identified A05 empty-input prerequisite.
