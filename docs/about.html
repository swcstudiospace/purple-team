What T3MP3ST is, how it is operated, and where the sources of truth live.

What this is

T3MP3ST is an authorized red-team console: missions drive real operators against targets you own or are permitted to test, every live action passes through scope receipts, and every claim lands in the evidence vault with provenance. Later kill-chain phases are honestly labeled where they are scaffolded rather than fully autonomous.

Operating contract

  • Same-origin API by default; the server contract is frozen — the UI never invents routes.
  • Tokens stay on this machine: subscriptions sign in server-side, keys live in local storage, masked everywhere.
  • Receipts gate live execution; Full Auto resumes with the exact approved receipt.
  • An explicit agent pin outranks a stored key; a stale pin never displaces a working provider.
